## Project Overview

The **OpenAPI Mock Server Generator** is a developer productivity tool that reads OpenAPI 3.0 YAML/JSON specification files and automatically generates mock REST API endpoints. The generated endpoints return schema-compliant responses, validate requests, and support configurable response latency for API testing.
